# Car Rental System — Client (React + Vite)

React frontend for the Car Rental System. Talks to the Node/Express/MongoDB API in `../server`.

## Setup

```bash
cd client
npm install
npm run dev
```

The dev server runs at `http://localhost:5173`.

## Environment variables (`.env`)

```
VITE_CURRENCY=₹
VITE_BASE_URL=http://localhost:3000
```
